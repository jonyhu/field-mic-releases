# Field Mic

Voice dictation for macOS. Press a key, speak, press it again, your words paste at your cursor.

## Install

Download the latest `.dmg` from [Releases](https://github.com/jonyhu/field-mic-releases/releases/latest), open it, and drag **Field Mic.app** to your Applications folder.

The first run walks you through getting a Cohere API key, granting microphone access, and granting accessibility (so the transcript can paste into other apps).

## Requirements

- macOS 12 (Monterey) or later
- Apple Silicon or Intel
- Internet connection (audio is sent to Cohere for transcription)

## Auto-updates

Field Mic checks this repo for updates on launch and applies them in-place.
